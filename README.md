The Self-Checkout Is Judging You — one funny line in the voice of a smug self-checkout machine, and a house judge picks the line that gets the biggest laugh.

> BEEP. Ma'am, the family-size ice cream at 9 a.m. on a Tuesday isn't a purchase, it's a cry for help — and yes, I am judging you.

## Run it

```sh
python3 main.py
```

Writes the single line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). Deterministic: no network, no randomness, no model calls — the same line every run.
